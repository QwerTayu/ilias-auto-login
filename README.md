# ilias-auto-login

長岡技大の ILIAS のログイン（LDAP 認証の選択 → ID・パスワード → ログイン）を自動で済ませる、Chromium 用の拡張機能です。ID とパスワードは拡張機能に持たせず、パスワードマネージャが入れたものを使います。

仕様は [SPEC.md](SPEC.md) にあります。

## 入れ方（Chrome・Dia など Chromium 系）

1. このリポジトリを clone する。
2. `chrome://extensions` を開き、右上の「デベロッパーモード」をオンにする。
3. 「パッケージ化されていない拡張機能を読み込む」を押し、clone したフォルダ（`manifest.json` があるフォルダ）を選ぶ。
4. ツールバーの拡張機能メニュー（パズルのアイコン）から「ILIAS Auto Login」をピン留めしておくと、オン・オフを切り替えやすい。

更新するときは `git pull` してから、`chrome://extensions` で「ILIAS Auto Login」の再読み込みボタンを押します。

## 動き

ILIAS（`https://cera-e1.nagaokaut.ac.jp/`）のログイン画面を開くと、次の順に動きます。

1. ログインオプションの「LDAP認証（統合アカウント）」を選ぶ。
2. ユーザ名とパスワードの欄が埋まるのを、最大 15 秒待つ。入れるのはパスワードマネージャ（1Password の拡張機能など）。15 秒たったら待つのをやめるが、欄に触れる（自動入力の候補を選ぶなど）と、そこからまた 15 秒待つ。
3. 2 つとも埋まったら「ログイン」ボタンを押す。

次のときは押しません。

- オフにしているとき（ツールバーのアイコンを押すと切り替わり、オフのときはバッジに `OFF` と出る）
- ログインに失敗した画面（エラーメッセージが出ている画面）
- 直前の自動ログインから 1 分たっていないとき（ブラウザを閉じるまでの記録。タブをまたいで数える）
- タブが裏にあるとき。表に出たときに動く
- 15 秒待っても欄が埋まらず、欄にも触れていないとき
- ID やパスワードを手で打ったとき（打っている途中で押さないため。自分で Enter を押す）

1 回のページ表示で押すのは 1 回までです。ID・パスワードの値は読まず、どこにも保存しません。

## パスワードマネージャについて

Chromium は、ブラウザ標準の自動入力で入った値を、ユーザーがページに触れるまで JavaScript から見えないようにしています。この拡張機能は値を読まず、`:autofill` で「入っている」ことを見て押します。

- **ブラウザ標準のパスワード保存**：Google Chrome（macOS）で確かめ、自動入力した値でログインできた。Mac の Chrome はページを開いただけでは入れず、ユーザ名の欄をクリックして候補を選ぶ（Touch ID を求められることがある）と入る。選んだ時点で、そこから 15 秒待ち直すので、ゆっくり選んでも押される。
- **1Password の拡張機能**：値を JavaScript から見える形で入れるので、同じように押される想定（Dia で使う）。

## 確かめたこと

Google Chrome（macOS）で、次を確かめました。

- ログイン画面を開くと「LDAP認証（統合アカウント）」が選ばれる
- 自動入力の候補を選ぶと、ログインボタンが押されてログインできる
- パスワードを間違えた画面（`.alert-danger` の「ユーザ名またはパスワードが間違っています」）では押さない
- 自動ログインから 1 分以内に、もう一度ログイン画面で入力しても押さない
- オフにしたら何もしない（LDAP 認証も選ばない）

ログイン後に、もともと開こうとしていたページへ戻す動き（SPEC の「あるとよいもの」）は、まだ作っていません。
